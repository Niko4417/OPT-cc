# Use one app to ask questions and add knowledge, and treat notes as project artifacts

A consultant uses one application both to ask questions and to add knowledge to a project memory, by uploading project artifacts or typing notes. A note typed into the app is a project artifact under ADR-0006, because a consultant adds it by hand. No separate, human-maintained knowledge store sits next to the project memory.

## Considered options

- Human-maintained knowledge pods as in Keiko, filled separately from the project memory. Rejected by the owner, who does not want their usefulness researched and wants one place to ask and add.
- A new term for notes. Rejected because "project artifact" already covers anything added by hand.
