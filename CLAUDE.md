## Agent skills

### Issue tracker

Issues and wayfinder maps live in GitHub Issues of Niko4417/OPT-cc. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels, each equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Decisions

Every final decision the owner makes gets an ADR in `docs/adr/`: at the end of each grilling session, and when a wayfinder ticket closes with a project decision. Decisions made while charting the map stay in the map's Notes until a ticket finalizes them; write their ADRs then. This replaces the domain-modeling skill's three-criteria test for when to write an ADR. Format, numbering and superseding rules: `docs/agents/domain.md`.
